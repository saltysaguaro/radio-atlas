# Sources and selection method

- [Radio Browser API documentation](https://docs.radio-browser.info/): public directory metadata, stream URLs, station IDs, tags, languages, click counts, vote counts, source connection-check dates, and optional coordinates. The service checks streams regularly; community metadata may contain errors.
- [Radio Browser](https://www.radio-browser.info/): station source. Directory data is provided as public/open data; this does not transfer copyright or rebroadcast rights to audio. Radio Atlas connects users directly to listed streams and does not cache, copy, relay or rebroadcast audio.
- [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/): public-domain 1:50m country boundaries, labels and map coordinates, bundled locally. Boundaries represent this cartographic dataset, not a political endorsement.
- [Natural Earth source GeoJSON](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson).
- [mledoze/countries](https://github.com/mledoze/countries): country and territory list and geographic centers for entries too small for map polygons; ODbL. Country data and station data remain available in the bundled catalog JSON; corresponding map geometry is in `world.geojson`. Preserve this attribution when redistributing.
- [Leaflet](https://leafletjs.com/): interactive map engine, BSD-2-Clause. React is MIT. Bundled dependency license texts are included in the published site.

## Catalog inclusion

Broadcaster additions are maintained in `supplemental-stations.json` and checked separately by `scripts/supplement_catalog.py`: [Bhutan BBS's official player](https://www.bbs.bt/radio-streaming/) and [FBC's SERE+ platform](https://www.sere.plus/). FBC streams were read from its public web application's API, linked by [FBC itself](https://www.fbc.com.fj/). The six FBC broadcast stations are included only when they pass the same secure audio probe. Supplemental records retain their source page URL and do not have invented directory popularity numbers or exact coordinates.

The refresh downloads the full directory, including records currently marked broken or stale, and evaluates every distinct candidate endpoint. It explicitly requests up to 100,000 records and continues if that page fills; directory UUIDs are deduplicated. The live check, rather than an old directory status or codec label, determines inclusion. The maintained broadcaster supplements participate in the same sweep. Both original and resolved endpoints are tested, preferring an original secure endpoint when it works. HTTP-listed addresses are tested over HTTPS on the same host, port and path; their insecure URLs are never requested. Successful upgrades retain their original URL as provenance.

There are no country quotas, popularity cutoffs or candidate sampling limits. Popularity determines display and duplicate preference only. Passing original and final stream URLs are deduplicated globally. Distinct endpoints with similar station names are retained because a normalized name alone cannot prove two stations carry the same programming. Multiple formats or regional versions may therefore remain; totals count distinct feeds, not independently audited broadcasters.

Each retained stream returns HTTP 200/206 with valid TLS, a supported direct audio MIME type (MP3, AAC or Ogg), and at least 4,096 bytes. Up to five redirects are allowed. Every destination must be HTTPS without embedded credentials and resolve only to public addresses. Curl is pinned to those checked addresses, bypasses environment proxies, and uses its normal certificate verification. Obvious HTML, JSON and playlist bodies are rejected. Feeds assigned to more than five countries are excluded as geographically ambiguous. Checks never bypass login, payment, TLS failures, geo restrictions or access controls.

The sweep uses up to 128 workers, with at most eight initial connections per hostname, a five-second connection timeout and a nine-second request timeout per hop. Check evidence is saved incrementally in `endpoint-checks.jsonl`; interrupted sweeps resume using results younger than 24 hours. The discovery report records every candidate's disposition in aggregate and each endpoint's outcome is available in the check log. Catalog replacement happens only after the sweep completes and passes a minimum-size guard. `supplement_catalog.py` is now a compatibility entry point for the full refresh; it is unnecessary in the normal pipeline.

HLS playlists and unsupported formats are excluded even when reachable: fetching a manifest does not verify browser playback of its segments. Web player pages, HTTP-only feeds and inaccessible endpoints are also excluded. Safety here describes transport checks, not editorial approval, malware certification or a claim that programming is suitable for every audience.

These checks establish point-in-time network availability from this computer. They do not decode every stream in every browser or verify every broadcaster's official identity. Community coordinates are not independently verified studio locations. Unknown coordinates are grouped at a clearly marked country-level location, with no fabricated station pins. Countries and territories with zero suitable streams remain selectable and show an empty state.

The finalizer applies canonical ISO country names, merges all map geometry sharing one country code, and checks station coordinates against the corresponding polygons (with a small coastal tolerance). Out-of-country coordinates are removed from the displayed pins and retained in `location-audit.json` for review. This catches obvious geographic metadata errors; it does not establish that the remaining coordinates are exact studio locations.

Records whose source coordinates are clearly far from their assigned country are excluded altogether rather than presented as verified country attribution. Remaining country assignments are still community metadata and may be imperfect.

## Coverage limits

The target is every distinct compatible feed that passes these checks in the available sources, with no per-country limit. `COVERAGE.md` records actual totals and gaps; `discovery-report.json` records source and exclusion totals. No directory covers all broadcasters worldwide. Community metadata may be missing, mislabeled or duplicated, while new stations and URLs appear continuously. No comparable worldwide audience dataset is used. Refresh periodically to track changes. The separate local country-research schedule records candidates only; it is not installed by cloning this repository, and GitHub Actions does not refresh or research stations.
